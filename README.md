# Siyuan He's Personal Website

A simple static personal website created for DS 501. It can be published directly with GitHub Pages—no build step is required.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository's **Settings** and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

GitHub will display the public site URL after the deployment finishes.
